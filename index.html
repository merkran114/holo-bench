          Searching

          Type part of a name. You can add a set code or card number too, like dragapult twm or ultra ball 131. Accents don't matter, so pokegear finds Pokégear.

          AI search

          Switch the search box to AI and describe what you need, like supporters that draw cards, basic water pokemon with free retreat or attackers that do 200+ damage. It reads the text of every card, shows how it understood you, and still uses your format, type and set filters.

          Tracking what you own

          Each deck row has an owned counter. Click it to count up the copies you have, right-click to count down. The shopping list then shows only what you're missing, with Cardmarket and TCGplayer prices.

          Where the data comes from

          Card data, images and prices come from the free TCGdex database. Decks, your collection and settings are saved in this browser only.
