# Holo Bench

A Pokémon TCG deck-building sandbox that runs in your browser. It's one file (`index.html`): open it, build decks with any card ever printed, and test them.

## What it does

- **Search every card**: by name, set code or number, with filters for format (Standard, Expanded, Unlimited), card type, Pokémon type, stage and set. An **AI** search mode understands plain English, like "supporters that draw cards" or "basic water pokemon with free retreat".
- **Build decks** with live rule checks (60 cards, 4 copies, Basic Pokémon, ACE SPEC, format legality), undo and redo, and several decks saved in your browser.
- **View deck** lays your deck out as card stacks, with opening-hand odds, price, and what you still need to collect.
- **Rate deck** scores the list in six categories and plays 20 quick test games against bot decks, then lists strengths and things to improve.
- **Play vs bot** on a Battle Academy-style playmat. The core rules and the most common card effects run automatically, and sandbox tools cover the rest.
- **Test hand** draws an opening hand, mulligans and Prize cards.
- **Collection and prices**: mark which cards you own, get a shopping list with Cardmarket and TCGplayer prices, find cheaper prints that play the same, and open any card on eBay, TCGplayer, Cardmarket or Limitless.
- **Import and export** decks in Pokémon TCG Live format.

## Using it

Open `index.html` in Chrome, Edge or Safari, or use the GitHub Pages link for this repository. It needs an internet connection. Decks, your collection and settings are saved in the browser you use, not online.

## Data

Card data, images and prices come from [TCGdex](https://tcgdex.dev), with missing images from the Scrydex image service used by pokemontcg.io.
